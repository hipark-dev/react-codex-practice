# React 컴포넌트 생성 및 수정

1. 작업 전에 프로젝트 루트의 `AGENTS.md`를 읽고 적용되는 개발 규칙을 확인한다.
2. 기존 컴포넌트 구조와 코딩 스타일을 분석하고 최대한 유지한다.
3. 함수형 React 컴포넌트를 사용한다.
4. 컴포넌트 Props는 `interface`로 정의한다.
5. TypeScript의 `any` 타입을 사용하지 않는다.
6. 공통 컴포넌트는 `src/components`에 생성한다.
7. 불필요한 상태 관리나 `useEffect` 사용을 피한다. 기존 값에서 계산할 수 있는 값은 별도 상태로 관리하지 않는다.
8. 새 컴포넌트를 만들기 전에 기존 컴포넌트를 재사용할 수 있는지 먼저 확인한다.
9. 필요한 경우 Vitest 테스트를 작성한다. 기존 테스트 환경을 먼저 확인하고, Vitest가 설치되어 있지 않으면 임의로 설치하지 않고 검증 제한을 보고한다.
10. 작업 후 프로젝트 루트에서 `npm run lint`와 `npm run build`를 실행한다.
11. 오류가 발생하면 원인을 분석하고 작업 범위 내에서 수정한 뒤 실패한 검증을 다시 실행한다. 해결할 수 없는 오류는 원인과 제한 사항을 보고한다.
12. 변경된 파일과 검증 결과를 한국어로 보고한다. 실행하지 못한 검증은 통과한 것으로 보고하지 않는다.
